# Security policy

Please report suspected vulnerabilities through
[GitHub's private vulnerability reporting](https://github.com/s9rg/ui-theme-builder/security/advisories/new).
Do not open a public issue containing exploit details.

Security fixes are provided for the latest published 0.x minor line. At launch, that is `0.5.x`.

The compiler treats project documents and adapter output as untrusted data. Third-party JavaScript
adapters, if supported later, will be trusted build-time code and require explicit installation.
